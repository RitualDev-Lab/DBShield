Frequently Asked Questions

Everything you need to know about DBShield security invariants.

How does DBShield differ from standard database firewalls?

Traditional firewalls look for SQL injection attacks from web users. DBShield is designed specifically for autonomous AI coding agents: it enforces AST row thresholds, prevents missing WHERE clauses, redacts PII before it streams into LLM context windows, and simulates mutations via two-phase dry-run transactions.

Can DBShield be used with ORMs like Prisma or Drizzle?

Yes. DBShield exposes a standard PostgreSQL Protocol 3.0 TCP proxy on port 5433. Point your DATABASE_URL to postgres://user:pass@127.0.0.1:5433/db and any ORM or client works seamlessly.
