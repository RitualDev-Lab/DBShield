# DBShield Governance & Maintainership

## Overview

DBShield is an open-source project created and maintained by **RitualDev Lab**. The project operates under an open governance model designed to foster community contributions while preserving strict security and reliability standards.

## Roles & Responsibilities

### Maintainers
Maintainers are responsible for:
- Reviewing and merging pull requests.
- Triaging security advisories and issuing prompt CVE fixes.
- Enforcing the Code of Conduct and architectural integrity.
- Releasing npm packages, Docker images, and Helm charts with cryptographic provenance.

### Contributors
Anyone can become a contributor by submitting issues, improving documentation, fixing bugs, or implementing approved features.

## Decision Making
Decisions regarding architecture, protocol additions, and security tiers follow an RFC process. Changes affecting backward compatibility require consensus among core maintainers.
