# dbshield-core 🦀

High-performance zero-GC wire protocol proxy engine, connection pooling, and virtual shadow database for **[DBShield](https://github.com/RitualDev-Lab/DBShield)**.

## Installation

```toml
[dependencies]
dbshield-core = "0.2.1"
```

## Features
- Zero-GC PostgreSQL and MySQL wire-protocol framing & inspection
- Connection pool primitives and dynamic PII data masking
- Virtual shadow database hooks for safe autonomous AI agent query execution
