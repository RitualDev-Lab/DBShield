# Accessibility Statement for DBShield

RitualDev Lab is committed to ensuring digital accessibility for people with disabilities. We continually improve the user experience for everyone and apply the relevant accessibility standards across our CLI, terminal monitors, and web interfaces.

## Conformance Status

The DBShield documentation website and live approval feed (`:3100`) target conformance with **WCAG 2.1 Level AA** guidelines.

### Measures Taken
1. **High-Contrast Terminal Output**: Terminal views and TUI monitors (`dbshield top`) support `--no-color` and standard ANSI color palettes distinguishable by color-blind users.
2. **Semantic HTML**: The web dashboard and documentation site use semantic landmarks (`<header>`, `<main>`, `<nav>`, `<section>`, `<footer>`) and ARIA roles for screen readers.
3. **Keyboard Navigability**: All interactive simulators, modals, and tables in the web dashboard can be operated via standard keyboard navigation (`Tab`, `Enter`, `Escape`).
